## Project-SmartHire

SmartHire is an intelligent web application that connects job seekers with employers
based on skills matching.

## Project Pages
1. Home Page (index.html)
2. Register Page (register.html)
3. Job Seeker Dashboard (jobseeker-dashboard.html)
4. Jobs Page (jobs.html)
5. Employer Dashboard (employer-dashboard.html)

## Technologies Used
- HTML5
- CSS3 (External only)
- jQuery
- AJAX
- JavaScript

## Features
### Job Seeker
- Add skills with levels
- View added skills
- Search for matching jobs
- Apply using AJAX (no page reload)

### Employer
- Add job postings
- View candidates
- Popup profile view
- Accept/Reject candidates
